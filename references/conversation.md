# 聊天、升温与邀约

以下是示例。起草时按用户实际经历、双方的熟悉程度和说话习惯改写。

| 场景 | 怎么选下一步 | 可发示例 |
| --- | --- | --- |
| 刚认识 | 用共同经历开场，问一个好回答的问题 | “你刚才提到那家书店，我还没去过。第一次去你会推荐逛哪一层？” |
| 聊天卡住 | 回应对方的情绪或经历，再决定是否问问题 | “连着开三场会也太累了。你先歇会儿，晚点有精神了再聊。” |
| 想升温 | 表达对具体互动的欣赏。对方接得住再加深 | “跟你聊旅行那段还挺开心的，我回去路上还在想你说的那个地方。” |
| 想见面 | 把共同兴趣变成轻量邀约，语气清楚 | “你上次说想看那个展，我打算周日下午去。你想一起吗？” |
| 见过面想再约 | 说一个真实感受，再提一个动作 | “今天一起散步挺开心的。你下周想不想一起吃个饭？” |
| 想确认关系 | 说自己的期待，询问对方的理解 | “我很喜欢我们现在的相处，也想认真和你交往。你是怎么看我们这段关系的？” |
| 想复联 | 先检查是否有明确拒绝或断联边界。没有边界且用户愿意承担无回应的可能，才考虑发一次 | “前两天路过我们之前聊过的那家店，想起你了。最近还好吗？” |

对方接受邀约时确认时间地点。有兴趣但没空时，可以请对方给一个方便的时间。对方模糊婉拒且没提替代时间时，把话题放回日常，别连续提约。对方明确拒绝时停止推进。

对方对关系的期待不一致时，帮助用户说清自己愿意接受什么。对方在想、需要时间时，可以约定双方都舒服的再谈时间。
