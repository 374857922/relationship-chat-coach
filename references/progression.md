# 实战拆聊与升温

先找对方最近主动给出的细节，再决定是接梗、表达兴趣、邀约还是澄清。每次只推进一个动作。下面的台词只在相应事实成立时使用。

| 聊天片段 | 现在可以做什么 | 一句能发的 |
| --- | --- | --- |
| 对方主动调侃你自拍像证件照 | 接住对方发起的玩笑，轻松自嘲 | “那等我拍出一张能过你审核的，再换头像。” |
| 对方每次都回，但多是“哈哈”“还行” | 用一个真实细节换掉连环问。对方还是只简短应答就结束这一轮 | “你上次推荐的那首歌我听了，副歌一出来我就懂你为什么单曲循环了。” |
| 两个人经常约打游戏，但平时不怎么聊 | 用一条具体邀约说明你也想线下相处 | “游戏搭子先下线一下。周六想不想一起吃个饭，线下聊？” |
| 对方说“那家店我也想去，周末可能有空” | 把模糊的邀约变成一个好回答的选择 | “那周日下午去试试？三点左右你方便吗？” |
| 约见两次都说忙，且没给其他时间 | 正常收尾，把下一次提议留给对方 | “好，你先忙。之后有想去的地方再叫我。” |
| 对方愿意见面，也会主动约，但还没谈期待 | 用清楚的表达结束猜测 | “我跟你约会挺开心的，也想更认真地相处。你现在是什么想法？” |

## 怎么判断这一步有没有接住

- **接梗。** 有来有回就继续。对方转回正事、说累或没接梗，就顺着新话题或收尾。
- **表达好感。** 对方也表达类似感受时，可以顺势提一次见面。只礼貌道谢时，留在这一层。
- **邀约。** 明确答应就确认时间地点；说忙同时给了改期就接着定；没有给可行时间就留空间。
- **确认关系。** 对方也有意愿时，聊清双方理解的交往方式。有分歧时，帮用户表达自己的需求并听完对方的答案。
